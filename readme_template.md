# ESP32 E-Paper Display Reader

![Project Banner](images/banner.jpg)

A portable ESP32-powered e-paper reading device with a web-based interface for transferring and reading text content.

---

## Features

- ESP32-based system
- E-paper display support
- Web UI for file transfer
- Lightweight and portable
- Low power display technology
- Open-source project

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Link2004tw/esp32-epaper-display-reader.git
```

### 2. Open in PlatformIO / Arduino IDE

Install required libraries and select the correct ESP32 board.

### 3. Upload the Firmware

Flash the firmware to the ESP32.

### 4. Access the Web UI

Connect to the device and open:

```md
http://<device-ip>
```
